# 竹影c 的 Minecraft 服务器官网

纯静态站点，**零依赖、零构建、零外链**（不联网也能正常打开），双击 `index.html` 就能看。

- 版本与玩法：**26.3 · 养老生电**，永久不删档，无氪金
- 进服方式：直播间卡灯牌 → 升到 3 级 → 私信发 4 张截图 → 拿群码进群
- 视觉：白金配色 + 液态玻璃（Liquid Glass）+ 首屏 3D 皮肤抱金块 + 3D 粒子

## 一、目录结构

```

├─ index.html                 页面本体（所有文字都在这里）
├─ assets/
│  ├─ css/style.css           全部样式（含液态玻璃层）
│  ├─ js/config.js            ★ 你要改的配置都在这

│  ├─ js/fx.js                首屏 3D 粒子（不要可以直接删引用）
│  ├─ download/AC26.3-client.zip  ★ 官网上的整合包下载就是这个文件
│  └─ img/
│     ├─ skin.png             ★ 3D 人物用的皮肤（64×64）
│     ├─ skyline.svg          首屏全息城市天际线（可删，删了首屏更简洁）
│     └─ favicon.svg          浏览器标签小图标
├─ screenshots/               desktop.png / mobile.png / 手机版长图.png（可直接发群）
├─ 启动预览.bat               双击本地预览
└─ README.md                  本文件
```

## 二、先改这几个（就一个文件）

打开 `assets/js/config.js`：

| 配置项 | 现在填的 | 说明 |
|---|---|---|
| `serverIp` | 空 | 玩家在游戏里填的地址。**留空**时首屏显示「进群获取」，不会露出空框 |
| `qq1` | `973042992` | 1 群 |
| `qq2` | `680984791` | 2 群 |
| `kuaishou` | 快手「竹影c」搜索页 | 换成你自己的主页链接最好 |
| `kuaishouId` | `zhuyingc1314` | 页面上显示的快手号 |
| `packDownload` | `assets/download/AC26.3-client.zip` | 整合包下载；已指向站点内自带的包，换包就改这里 |


改完保存刷新即可，全站出现这些信息的地方都会自动同步。


## 三、换成你自己的皮肤

首屏那个抱着金块的小人，是用 `assets/img/skin.png` 实时贴出来的：

1. 打开皮肤站（如 mineskin / NameMC），下载你的 **64×64 皮肤文件**（经典模型），
2. 改名覆盖 `assets/img/skin.png`，
3. 刷新页面——不用改任何代码，头/身/手/腿的每个面都会自动对上。

> 只支持 **64×64 的经典（Steve）模型**。3px 细手臂（Alex）皮肤也能显示，但手臂会略宽。
> 想换姿势：`style.css` 里搜 `.av .arm`，改 `rotateX(62deg)` 是抬手角度，`rotateY(5deg)` 是内收角度。

## 四、换掉二维码占位图

把群二维码截图存成 `assets/img/qq-qr.png`（正方形，400×400 以上）即可。
图片不存在时会自动显示「二维码 / 待替换」的占位格，不会出现裂图。

## 五、本地预览

- **最简单**：双击 `index.html`。
- **推荐**：双击 `启动预览.bat`，自动开本地服务器并打开 `http://127.0.0.1:8910/`（复制群号这类功能更稳）。

## 六、放到网上（三选一）

1. **GitHub Pages（免费）**：新建仓库 → 上传本目录所有文件 → Settings → Pages → 选 main 分支。
2. **静态托管**：Vercel / Netlify / 阿里云 OSS / 腾讯云 COS，整个文件夹拖进去，入口 `index.html`。
3. **自己的服务器**：丢进任意 Web 服务器目录，纯 HTML 不需要 PHP、数据库。

> 全站都是相对路径，放在子目录（比如 `yoursite.com/mc/`）里也能正常显示。

## 七、内容维护

- **改文案**：都在 `index.html`，中文直接搜关键词（「灯牌」「四张截图」「一律封号」）。
- **四步进服流程**：搜 `进服要走灯牌`，在 `.steps` 里改每步的 `<h4>` 和 `<p>`。
- **禁止事项**：搜 `服务器禁止`，在 `.warn-list` 里增删 `<li>`。
- **特色卡 / 进服步骤 / 教程 tab**：复制相邻的整块标签改内容，数量不用改代码。
- **配色**：`style.css` 顶部 `:root` 里的 `--gold` 系列变量。
- **玻璃强度**：`style.css` 里 `--gl-blur`（模糊）、`--gl-bg`（透明度）两个变量调。

## 八、几个已知的可选项

- 不想要首屏粒子：删掉 `index.html` 里的 `<canvas class="fx-canvas" id="fxCanvas">` 和底部 `<script src="assets/js/fx.js">`。
- 不想让人截图盗用？没做防护——静态站挡不住，介意的话只放群公告里。
- 服务器地址建议始终留空、只在群公告发，防止被外挂/熊孩子直接扫到。
