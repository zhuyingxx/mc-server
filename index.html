03 / GUIDE

从零开始，手把手教你进服

没装过客户端也没关系，照着点一遍就行。卡住了直接在群里问，别自己硬折腾。

  1. 下载 PCL2 启动器

    去 PCL2 官网下载最新版，是单个 .exe 文件，免安装。别从乱七八糟的下载站下，容易带东西。

  2. 放到 D 盘

    新建一个文件夹，比如 D:\MC\PCL，把启动器放进去。放 C 盘桌面有时候会因为权限写不进文件。

  3. 让它自己装 Java

    新版 PCL 会自动匹配并下载对应的 Java，不用自己折腾。群文件里也放了打包好的 Java，装不上就用那个。

  4. 把下载源改成镜像

    设置 → 启动器 → 下载源 → 选「镜像下载」。国内直连官方源经常卡住不动。

  1. 进群下载客户端

    下载 AC26.3基础整合包.zip（上面「整合包」那块就能直接下）。不要解压，PCL 要的就是压缩包。

  2. 导入

    打开 PCL2 → 左上「版本列表」→ 右上角「导入整合包」→ 选中刚才那个 zip，等它自己解压完。

  3. 确认版本出现

    列表里出现「AC26.3基础整合包」就说明成功了。点它右边的齿轮进设置。

  4. 分配内存

    内存给 4096–6144 MB。生电机器多、区块加载大，给少了会卡，但也别把内存条拉满。

  1. 启动游戏

    选好「AC26.3基础整合包」，点启动。第一次进会慢一点，属于正常现象。

  2. 添加服务器

    主菜单 →「多人游戏」→「添加服务器」。名称随便写，地址填 进群获取，注意别多打空格。

  3. 进服先看告示牌

    出生点有规则告示牌，写着哪些能做、哪些会被 ban。读完再动手，别一进去就挖别人家门口。

  4. 连不上？

    先看群公告是不是在维护或换周目，再看地址有没有多打空格。都没问题就在群里 @ 管理。

先说结论

安卓手机可以玩，装完和电脑上是同一个服务器、同一个存档；苹果手机基本别折腾，下面有说明。

  1. 下载 FCL 启动器（安卓）

    FCL（Fold Craft Launcher）是手机上跑 Java 版的启动器，免费、中文。群文件里有安装包，也可以应用商店搜「FCL」。装的时候手机可能提示「未知来源」，允许即可。

  2. 让它装 Java

    第一次打开 FCL 会提示安装 Java 运行环境，点「安装」，等它自动下完（大概 200 MB，用 WiFi）。这一步不装后面启动不了。

  3. 导入整合包

    把 AC26.3基础整合包.zip 存到手机里 → FCL 主界面「整合包」→「导入」→ 选中它。手机解压慢，等 3–5 分钟别退出。

  4. 内存给 2–3 GB

    在整合包设置里把内存调到 2048–3072 MB。给多了安卓会直接杀掉游戏，反而进不去。

  5. 进服务器

    启动后进「多人游戏」→「添加服务器」，地址填群公告里那个。第一次加载地形会卡十几秒，正常。

  6. 卡的话这样调

    视频设置里渲染距离拉到 4–6，关掉光影，关掉「平滑光照」和「实体阴影」。虚拟按键不顺手可以在 FCL 里换布局。

适合拿手机干什么 挂机、收菜、看家、盯熔炉 临时上线跟人说句话 躺床上逛自己家
别指望手机干这些 在红石机器堆里建大工程 挂光影截图 长时间挂机（发烫、掉电快）
苹果手机（iPhone）能玩吗

能，但要自己给 PojavLauncher iOS 签名（AltStore 之类），证书 7 天掉一次，每次都得重签，而且 26.3 这种新版本兼容性很差。老实说：别折腾，用电脑，或者电脑开着远程控制。

手机和电脑的存档是通的吗

服务器是同一个，你在哪台上线看到的都是同一个世界。但手机上是独立客户端，本地单人存档不互通。

手机装完还要重新走一遍灯牌流程吗

不用。灯牌是进群+白名单的门槛，走完一次就行，之后换设备用同一个游戏 ID 进服即可。

启动就闪退 / 报 Java 错误

基本是 Java 版本不匹配。PCL 设置里选「自动选择 Java」，或者用群文件里那份打包好的 Java，手动指过去。

卡在「正在连接服务器」

先看群公告，服务器是不是在维护或重启。没维护的话，检查地址有没有多打空格、是不是把 : 打成了中文冒号。

掉帧、内存不足

内存调到 6144 MB，视频设置里把渲染距离降到 8–10。客户端自带 Sodium，在它里面调比原版快很多。

进不去，提示不在白名单 / 没权限

说明灯牌流程还没走完，或者私信时 ID 填错了。回群里找管理核对，ID 区分大小写。

机器太多，服务器卡怎么办

先看是不是实体堆积（鸡、村民、掉落物）。生电可以造，但别为了测试挂几百个实体，管理会找你聊。
